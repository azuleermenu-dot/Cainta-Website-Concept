# EMD Cainta Market & Trading Center — Website Concept

A responsive, interactive website concept for EMD Cainta Market & Trading Center and the BBMC Muslim Community.

## Stack
- React 19 + Vite + TypeScript
- Framer Motion
- Lucide React
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
npm run build
npm run preview
```

## Concept and authenticity
This repository contains a **website concept**, not an official organizational website. Vendor names, photos, listings, facilities, and community announcements are demonstration content only. No organizational history, leadership, statistics, operating hours, official contacts, vendor partnerships, or facility claims are asserted. Replace demo content only after the organization verifies and supplies the information.

The contact form currently validates and displays a local demo confirmation. It does not send or store messages.

## Features
- Responsive desktop and mobile navigation
- Marketplace category filters
- Live vendor search and empty state
- Vendor detail modal
- Concept facility showcase
- Sample community announcement board
- Contact form validation and local confirmation
- Smooth section navigation, lazy-loaded imagery, reduced-motion support
- SEO metadata and semantic landmarks

Images are loaded from Unsplash and require an internet connection.
